# Mobile Sales Dashboard | Power BI
## Project Overview
The Mobile Sales Dashboard is an interactive Power BI solution designed to analyze mobile phone sales performance across different cities, brands, payment methods, and time periods. This dashboard helps businesses monitor key sales metrics, identify trends, and make data-driven decisions through dynamic visualizations and filtering options.
- <a href ="https://github.com/analytical31/Mobile-Sales-Analysis/blob/main/Mobile%20Sales%20Data.xlsx"> Data-set</a></br>
## Objectives</br>
<br> Monitor overall mobile sales performance.
Track monthly sales and quantity trends.
Compare sales across different brands and mobile models.
Analyze customer payment preferences.
Evaluate transaction volumes and product ratings.
Identify high-performing cities and regions.</br>
## Key Performance Indicators (KPIs):</br>
Total Sales: ₹769M</br>
Total Quantity Sold: 19K Units</br>
Total Transactions: 4K</br>
Average Price: ₹40.11K</br>
- <a href ="https://github.com/analytical31/Mobile-Sales-Analysis/blob/main/Mobile%20sales.pbix"> Mobile Sales Dashboard</a></br>
## Dashboard Features</br>
1. Interactive Filters
Mobile Model Filter
Payment Method Filter
Brand Filter
Month-wise Navigation</br>
2. Sales Analysis
Total Sales by City (Map Visualization)
Total Sales by Mobile Model
Total Sales by Day of Week
Brand-wise Sales and Transaction Summary</br>
3. Quantity Analysis
Monthly Quantity Sold Trend
Quantity Performance Comparison Across Months</br>
4. Customer Payment Insights
UPI Transactions
Debit Card Transactions
Credit Card Transactions
Cash Transactions</br>
5. Customer Rating Analysis
Good Ratings
Average Ratings
Poor Ratings</br>
6. Time Intelligence
Month-to-Date (MTD) Performance
Same Period Last Year Comparison</br>
## Tools & Technologies Used</br>
Power BI for Dashboard Development</br>
Power Query for Data Transformation</br>
DAX (Data Analysis Expressions) for KPI Calculations</br>
Excel/CSV Dataset for Data Storage and Processing</br>
